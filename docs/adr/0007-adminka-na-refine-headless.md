# 0007. Админка на Refine (headless), свой UI на токенах дизайн-системы

## Контекст
В спецификации два противоречащих места: раздел «Решения по реализации» говорил «без Refine — вес и абстракции не окупаются на 9 разделах», дополнение после проверки возвращает Refine по рекомендации ТЗ §10.1. В правилах проекта и в сданной админке (T10) используется Refine.

## Решение
Админка — React + Vite + Tailwind + TanStack Query на Refine в headless-режиме: data provider читает списки как `{items, total}`, а весь UI собран из общих компонентов и токенов дизайн-системы. Действует дополнение: это решение последнее.

## Почему
- Готовая тема/UI-набор Refine отвергнута: админка должна выглядеть одним продуктом с Mini App и работать с телефона, на токенах `design-system/`.
- Самописная админка без Refine отвергнута в дополнении: ТЗ рекомендует Refine, и таблицы, фильтры и CRUD по многим разделам он даёт готовыми.

## Последствия
- Остаётся зависимость от Refine и его контракта data provider (`meta.query`), каждый раздел подгоняется под него.
- Старая запись «без Refine» осталась в спецификации; читать надо дополнение, иначе новичок решит, что Refine не используется.
- Админка не имеет права на литеральные цвета: любое расхождение с токенами видно как баг.
