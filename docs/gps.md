# Подключение GPS к байку

Трекер отправляет координаты на API, а админка показывает байк на карте и его трек. Точки хранятся 30 дней, затем удаляются.

## Быстрый способ: телефон в байке

1. Админка → «Мониторинг» → нужный байк → «Подключить GPS».
2. Скопируй адрес вида `https://<домен>/api/gps/gps_…`. Адрес содержит секрет.
3. На телефоне установи Traccar Client, впиши этот адрес как адрес сервера и включи отправку.

Адрес строится из `API_PUBLIC_URL`, поэтому он должен быть доступен из интернета. Адрес туннеля меняется при перезапуске `cloudflared`: после этого подключение нужно настроить заново, и сохранённые в телефоне адреса перестанут работать.

Если адрес утёк, нажми «Отключить GPS» и подключи заново: старый перестанет работать.

## GPS-маячок через Traccar Server

Маячки (SinoTrack, Teltonika и другие) работают по собственным протоколам. Их принимает [Traccar Server](https://www.traccar.org/), а он передаёт точки сюда.

1. В `.env` API задай `GPS_FORWARD_SECRET` — длинную случайную строку.
2. В `traccar.xml`:

   ```xml
   <entry key='forward.enable'>true</entry>
   <entry key='forward.url'>https://<домен>/api/gps/forward?secret=<секрет>&amp;id={uniqueId}&amp;lat={latitude}&amp;lon={longitude}&amp;speed={speed}&amp;timestamp={fixTime}</entry>
   ```

3. В карточке байка нажми «Подключить GPS» и укажи ID устройства из Traccar (обычно IMEI).

## Формат приёма

`GET` или `POST` на `/api/gps/<секрет>` или `/api/gps/forward`:

- OsmAnd: `lat`, `lon`, `speed` (узлы), `batt` (%), `timestamp` (секунды, миллисекунды или ISO);
- JSON новых Traccar Client: `{ location: { timestamp, coords: { latitude, longitude, speed }, battery: { level } } }`, скорость в м/с.

Неизвестный секрет — 404, координаты вне диапазона или время в будущем — 400. Точки чаще одной в 5 секунд отбрасываются.

## Тревога «едет без аренды»

Скорость от 15 км/ч при отсутствии выданной брони: бот предупреждает менеджеров и администраторов не чаще раза в час. Ложное срабатывание возможно, когда сотрудник сам перегоняет байк.

## Персональные данные

Трек арендованного байка показывает перемещения клиента. Клиента нужно предупредить об этом в договоре. Текст договора редактируется в админке: «Настройки».
