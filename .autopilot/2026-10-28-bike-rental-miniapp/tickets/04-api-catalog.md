## Что должно заработать

API отвечает на всё, что нужно до брони. `POST /auth/telegram` проверяет подпись initData (HMAC-SHA256 ключом бота, auth_date ≤ 24 ч) и выдаёт JWT на 24 ч; роль по Telegram ID (`ADMIN_TELEGRAM_IDS`, роли в БД); `DEV_AUTH=1` — тестовые пользователи. `PATCH /me`. Каталог с доступностью на даты (свободные байки модели с учётом брони, буфера, ремонта), ценой в день и итогом через `shared.quote`, `busyUntil`, все фильтры и сортировки из истории 65, `count`; `GET /models/{id}` (галерея, характеристики, тарифная сетка, что входит, условия); `GET /models/{id}/availability?month`; `GET /home`; `GET /now`; `POST /quotes` (с опциями и доставкой); избранное; `POST /events`; `GET /i18n/{lang}` с переопределениями. Каталог и расчёт цены — p95 ≤ 300 мс на сиде (индексы).

## Критерии приёмки

- [ ] Поддельный или просроченный initData → 401; валидный → JWT и роль
- [ ] `GET /models?from&to` не показывает свободными модели без свободного байка; занятые несут `busyUntil`
- [ ] Итог в каталоге совпадает с `POST /quotes` для тех же дат
- [ ] Фильтры и сортировки из истории 65 работают, `count` совпадает с числом элементов
- [ ] `availability?month` возвращает даты, на которые нет ни одного свободного байка модели
- [ ] Избранное доступно только своему пользователю
- [ ] Тест: каталог и quote на сиде укладываются в 300 мс
