## Что должно заработать

Админка открывается с телефона и компьютера: вход через Telegram Login Widget (проверка подписи) → сессия; в dev — тестовый вход. Роли: админ видит всё, менеджер — брони, шахматку и парк своей точки без цен, настроек и платежей. Дашборд: выдачи и возвраты сегодня, загрузка парка %, выручка день/неделя/месяц, неоплаченные брони, счётчики воронки. Брони: список с фильтрами по статусу, датам, точке; карточка с историей статусов, платежами, документами (временные ссылки), фотоактами. Шахматка: байки строками, дни колонками, брони полосами, перетаскивание на другой байк (конфликт → причина), ручная бронь для клиента «с улицы». Журнал действий. Плашка «Демо-данные — замените», пока в БД есть `isDemo`.

## Критерии приёмки

- [ ] Поддельные данные Login Widget → 401; менеджер не открывает настройки и платежи (403)
- [ ] Перетаскивание брони на занятый байк отклоняется с причиной, на свободный — сохраняется
- [ ] Ручная бронь проходит те же проверки доступности
- [ ] Дашборд считает выручку и загрузку по данным сида — тест
- [ ] Каждое изменение брони пишется в журнал
