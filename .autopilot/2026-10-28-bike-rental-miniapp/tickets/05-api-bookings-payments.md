## Что должно заработать

Бронь создаётся транзакцией: свободный байк модели `FOR UPDATE SKIP LOCKED`, вставка, конфликт → 409 `BIKE_TAKEN`; VietQR → «Ожидает оплаты» с удержанием 15 мин (задача BullMQ отменяет), наличные → «Подтверждена» (или предоплата при `cashPrepayPercent` > 0). `PaymentProvider`: `PayOsProvider` (VietQR, код брони в назначении, проверка подписи и IP webhook) и `TestProvider` (`POST /dev/payments/{id}/pay` в dev); `markPaid` идемпотентен, недоплата/переплата → «Проблема». Машина статусов, отмена с суммой возврата по правилам, неявка через `noShowHours`, депозит строкой, запись возврата. Документы: presigned upload в приватный бакет с SSE, согласие на обработку при первой загрузке, ссылки на чтение ≤ 10 мин только менеджеру/админу, ежедневная очистка через `docRetentionDays`. Rate limit 10/мин на создание броней и платежей; журнал действий; доступ к чужим броням и документам → 404.

## Критерии приёмки

- [ ] Интеграционный тест: две параллельные брони последнего байка → одна успешная, одна 409 `BIKE_TAKEN`
- [ ] Неоплаченная бронь через 15 мин → «Отменена системой», байк снова доступен (тест с подменой времени)
- [ ] Повторный webhook не создаёт второй оплаты; неверная подпись → 400
- [ ] Недоплата и переплата → статус «Проблема»
- [ ] Отмена за 30 ч → 100%, за 10 ч → 50%, за 1 ч → 0
- [ ] Чужая бронь и чужой документ по подмене ID → 404
- [ ] Ссылка на документ живёт ≤ 600 с и выдаётся только менеджеру/админу
- [ ] Срок меньше `minRentDays` и выдача раньше `now + minLeadMinutes` отклоняются при создании брони (400 с кодом)
- [ ] `TestProvider` позволяет оплатить без аккаунтов; `PayOsProvider` включается переменными `PAYOS_*`
