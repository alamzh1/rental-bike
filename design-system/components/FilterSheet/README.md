# FilterSheet

Нижняя шторка фильтров каталога с крупными вариантами и слайдером цены.

**Что подать:** группы фильтров (тип, объём, цена, бренд, опции, сортировка), текущие значения и число подходящих байков для кнопки.

- Шторка на `surface-raised` с `radius-xl` сверху, ручка `line-strong`, затемнение `scrim`. Выезжает за 250 мс.
- Заголовок `title-2` и текстовая кнопка «Сбросить» справа.
- Варианты — `Chip` в режиме `--option`, можно выбрать несколько в группе.
- Слайдер цены — двойной, заливка `accent`, подписи в валюте отображения.
- Кнопка внизу показывает результат: «Показать 12 байков». Если 0 — «Ничего не нашлось» и `disabled`.
