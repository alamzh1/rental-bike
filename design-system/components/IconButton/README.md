# IconButton

Круглая кнопка с одной иконкой: назад, фильтры, связь, избранное.

**Что подать:** иконку `br-i-*` и обязательный `aria-label` на языке интерфейса.

- `br-iconbtn` — 44px с рамкой `line` на `bg`: шапка экрана.
- `--inverse` — кнопка фильтров рядом с поиском.
- `--surface` — вторичные действия в карточке брони.
- `--float` — 32px поверх фото (сердце), зона касания расширена до 44px. Состояние `aria-pressed="true"` красит иконку в `favorite`; сменить иконку на `br-i-heart-fill`.
- Системное «Назад» — `Telegram.BackButton`. Своя кнопка «Назад» нужна только в браузерном превью и в полноэкранном режиме.
