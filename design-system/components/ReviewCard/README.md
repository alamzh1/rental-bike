# ReviewCard

Отзыв в горизонтальной ленте карточки модели.

**Что подать:** инициалы или аватар, имя, дату и срок аренды, оценку 1–5, текст на языке автора.

- Карточка 272px на `surface-raised` с рамкой `line`, текст обрезается на третьей строке.
- Под лентой — текстовая кнопка «Все отзывы (24)».
- Текст отзыва не переводим автоматически; язык отзыва — как написал клиент.
