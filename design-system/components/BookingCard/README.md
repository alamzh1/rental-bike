# BookingCard

Карточка брони во вкладке «Мои брони»: номер, статус, байк, даты, сумма, таймер и действия.

**Что подать:** номер брони, статус, модель и фото, интервал со временем, итог, время до выдачи или возврата, доступные действия.

- Статус — `StatusBadge` справа от номера.
- Таймер зависит от статуса: «До выдачи», «До возврата», «Бронь держится ещё 14:32» (цвет `warning`, обновляется каждую секунду).
- Действия по статусу: Подтверждена — «Как добраться», «Связаться», «Отменить»; Выдана — «Продлить», «Сообщить о проблеме»; Ожидает оплаты — одна главная кнопка «Оплатить …»; Завершена — «Оценить поездку».
- Открывается по `startapp=booking_<id>` из сообщения бота.
