# StatusBadge

Бейдж статуса брони: слово плюс цветная точка.

**Что подать:** название статуса из списка ниже на языке клиента.

| Статус | Класс |
| --- | --- |
| Ожидает оплаты | `br-badge--warning` |
| Подтверждена | `br-badge--accent` |
| Выдана | `br-badge--success` |
| Завершена, Отменена клиентом, Отменена системой | `br-badge--neutral` |
| Проблема | `br-badge--danger` |

- Статус всегда читается словом; цвет только дублирует его.
- `br-badge--plain` убирает точку: для служебных меток вроде «Нужны права A».
