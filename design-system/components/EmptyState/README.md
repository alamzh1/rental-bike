# EmptyState

Пустой экран: иконка, заголовок, одна строка пояснения и кнопка с действием.

**Что подать:** иконку раздела, заголовок, пояснение, текст и обработчик кнопки.

| Экран | Заголовок | Кнопка |
| --- | --- | --- |
| Мои брони | Пока нет броней | Выбрать байк |
| Избранное | Здесь будут сохранённые байки | Открыть каталог |
| Каталог с фильтрами | Ничего не нашлось | Сбросить фильтры |
| Нет байков на даты | Все байки заняты на 12–19 ноября | Сдвинуть даты |

- Пояснение говорит, что сделать, а не что пошло не так.
