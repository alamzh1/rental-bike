# RangeCalendar

Календарь выбора интервала аренды: первое касание — начало, второе — конец.

**Что подать:** месяц, занятые даты для модели (`GET /models/{id}/availability`), выбранный интервал, цену за период и рабочие часы точки.

- Начало и конец — квадрат `accent` с `on-accent`, дни между — полоса `accent-soft`.
- Даты без свободного байка — `disabled`, зачёркнуты и не нажимаются.
- Время выдачи и возврата — слоты по 30 минут в часы точки (по умолчанию 08:00–20:00), выбираются контурными `Chip`.
- Итог под календарём: «7 дней · 12–19 ноября · 910 000 ₫».
- Неделя начинается с понедельника в RU и VI, с воскресенья в EN.
- Каждое касание даты — `HapticFeedback.selectionChanged()`.
