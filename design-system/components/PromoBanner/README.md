# PromoBanner

Промо-баннер на главной: тёплая плашка `promo` с заголовком, строкой условий, кнопкой и фото байка.

**Что подать:** заголовок (до 30 знаков), строку условий, текст кнопки и фото из админки на трёх языках.

- Фон `promo`, текст `on-promo`, кнопка тёмная (`on-promo` с текстом `promo`). Цвета одинаковы в обеих темах.
- Один баннер на экран. Если акций несколько — горизонтальная прокрутка с точками.
- Без таймеров и восклицательных знаков в заголовке.
