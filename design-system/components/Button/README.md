# Button

Кнопка действия: главная синяя, тёмная, светлая и текстовая, в трёх высотах.

**Что подать:** текст-глагол («Забронировать», «Оплатить 1 149 000 ₫»), при необходимости иконку `br-i-arrow-right` справа. Для `--square` — только иконку и `aria-label`.

| Вариант | Классы | Когда |
| --- | --- | --- |
| Главная | `br-btn br-btn--primary` | Одно целевое действие экрана: «Забронировать», «Оплатить» |
| Тёмная | `br-btn--inverse` | Применить выбор: «Показать 12 байков» |
| Светлая | `br-btn--secondary` | Второе действие рядом с главной: «Сбросить», «Продлить» |
| Текстовая | `br-btn--ghost` | Ссылки внутри экрана: «Все отзывы», «Как добраться» |

Высоты: `--lg` 52px (низ экрана, шторка), без модификатора 44px, `--sm` 36px с невидимой зоной до 44px (карточка каталога). `--block` растягивает на ширину.

- Одна `--primary` на экран. Если внизу показан Telegram `MainButton`, своя главная кнопка не дублируется.
- Текст не обрезается: на VI и RU кнопка растёт. Вниз — только `--block`.
- `disabled` объясняет причину текстом кнопки («Нет на эти даты»), а не просто сереет.
