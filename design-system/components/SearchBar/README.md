# SearchBar

Шапка главной: приветствие по имени из Telegram, поле поиска и кнопка фильтров.

**Что подать:** `first_name` из `initDataUnsafe.user`, плейсхолдер поиска, обработчик кнопки фильтров (открывает `FilterSheet`).

- Приветствие — `title-1`, подзаголовок — `body` в `ink-muted`, одна строка.
- Поле — пилюля 48px на `surface`. При вводе показывает результаты сразу, без кнопки «Найти».
- На кнопке фильтров при активных фильтрах — счётчик в кружке `accent`.
