# Skeleton

Заглушка загрузки по форме будущего контента. Используется вместо спиннера в каталоге, бронях и отзывах.

**Что подать:** контейнер с `aria-busy="true"` и блоки `br-skel` с размерами реального содержимого.

- Цвет `skeleton`, лёгкий перелив 1.2 с; при `prefers-reduced-motion` перелив отключён.
- Показывать не дольше нужного: если ответ пришёл быстрее 200 мс, скелетон не рисуем.
- Ошибка загрузки заменяет скелетон блоком `br-note--danger` с кнопкой «Повторить».
