# PriceBreakdown

Детализация суммы в оформлении брони: аренда, опции, доставка, скидка, итог и отдельно депозит.

**Что подать:** строки из `POST /quotes` — название, сумму; итог; пересчёт; размер депозита.

- Строки — `body`, суммы справа табличными цифрами. Скидка — `success` со знаком «−».
- Итог — 17px 800 над линией `line`; пересчёт с «≈» под ним в `ink-muted`.
- Депозит — отдельный блок на `surface` с условиями возврата. Он не входит в итог аренды.
- Бесплатные позиции (2 шлема, замок, дождевик) в детализацию не выводим — они в карточке модели.
