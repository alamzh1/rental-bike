# TabBar

Плавающее тёмное нижнее меню из четырёх вкладок: Главная, Мои брони, Избранное, Профиль.

**Что подать:** текущую вкладку (`aria-current="page"`), подписи на языке интерфейса, счётчик активных броней при наличии.

- Панель `nav` высотой `tabbar-height`, `radius-xl`, отступ `space-3` от краёв и нижней safe area.
- Активная вкладка — пилюля `accent` с иконкой и подписью; остальные — иконки `nav-icon` с `aria-label`.
- Скрывается на экранах оформления и оплаты, где внизу стоит `PriceBar` или `MainButton`.
- В контенте над меню — резерв `tabbar-height` + `space-12`.
