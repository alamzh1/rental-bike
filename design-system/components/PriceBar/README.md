# PriceBar

Плавающая нижняя панель карточки модели: итог за период и кнопка «Забронировать».

**Что подать:** итог в донгах, срок, пересчёт в валюту отображения, обработчик кнопки.

- Панель `nav` с `radius-xl` и `shadow-nav`, тёмная в обеих темах. Стоит на `space-3` выше нижней safe area.
- Итог — `price-lg` в `on-nav`, строка срока и «≈ 3 220 ₽» — `caption` в `nav-icon`.
- Если используется Telegram `MainButton`, панель показывает только итог, а кнопку рисует Telegram (`accent`, `on-accent`).
