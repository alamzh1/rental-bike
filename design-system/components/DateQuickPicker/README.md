# DateQuickPicker

Блок «Когда нужен байк?» вверху главной: быстрые сроки, выбранный интервал и точка выдачи.

**Что подать:** выбранный интервал (начало и конец со временем), число дней, название точки и её часы работы.

- Быстрые кнопки: Сегодня, Завтра, 3 дня, Неделя, Месяц. Нажатие сразу пересчитывает каталог и итоговые цены.
- Строка интервала открывает `RangeCalendar` в шторке.
- Даты выбираются один раз и сохраняются на всём пути до оплаты.
- Время показывается в часовом поясе точки (UTC+7), формат по языку: «12 ноя, 10:00», «12 Nov, 10:00 AM».
