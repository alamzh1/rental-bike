# BikeCard

Карточка модели в каталоге: фото, рейтинг, избранное, характеристики, цена в день и итог за период.

**Что подать:** название модели, год, объём, тип КПП, рейтинг, цену в день по тарифу выбранного срока, итог за период, флаг избранного и статус доступности.

- Сетка 2 колонки — `br-grid`; горизонтальная лента «Популярные» — та же карточка шириной 160px.
- Фото — `.br-photo` на `surface-raised` внутри карточки на `surface`.
- Цена — `price`, «/день» и итог — `caption` в `ink-muted`. Итог пересчитывается при смене дат.
- Модель, занятая на даты, остаётся в сетке: `br-bike--busy`, бейдж «Занят до 21.11», без кнопки.
- Для моделей 150+ см³ под метаданными — бейдж `br-badge--plain br-badge--warning` «Нужны права A», если у клиента указана категория A1.
- Нажатие на карточку открывает карточку модели; стрелка — тот же переход, крупная цель для большого пальца.
