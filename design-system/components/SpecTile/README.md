# SpecTile

Плитка характеристики в карточке модели: иконка, подпись, значение. Ряд по 3.

**Что подать:** иконку, подпись и значение с единицами.

- Шесть плиток в фиксированном порядке: объём, КПП, расход, бак, макс. скорость, мест.
- Иконка в контурном квадрате `accent-text`, подпись `ink-muted` 12px, значение `body-strong`.
- Единицы в значении через неразрывный пробел: «125 см³», «95 км/ч». Десятичная запятая в RU и VI, точка в EN.
- Не больше шести плиток; остальное — список «Что входит бесплатно».
