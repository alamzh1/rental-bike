# Chip

Переключатель-фильтр: чипы категорий на главной и крупные варианты в шторке фильтров.

**Что подать:** короткий текст и состояние `aria-pressed`. Группа — в обёртке `br-chips` с `role="group"` и `aria-label`.

- `br-chip` (36px, пилюля): категории на главной и быстрые даты. Ряд прокручивается вбок — `br-chips--scroll`.
- `br-chip--option` (44px, `radius-sm`, рамка `line-strong`): варианты в шторке фильтров, как в референсе Insightlancer.
- Выбранный — `inverse` / `on-inverse`. Синий для выбора не используем.
- Каждое нажатие — `HapticFeedback.selectionChanged()`.
- Не превращать чип в кнопку действия: «Забронировать» — это `Button`.
